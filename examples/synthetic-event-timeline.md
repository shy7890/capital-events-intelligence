# 合成事件时间线 Demo

> 本示例完全合成，仅用于展示数据流，不对应真实发行人、证券代码、交易、价格或投资机会。

## 1. 输入：一条公告

示例公告称，**示例能源有限公司**正在评估一项战略资产交易。

## 2. 归一化记录

```json
{
  "issuer": "示例能源有限公司",
  "event_type": "资产交易",
  "announcement_date": "YYYY-MM-DD",
  "source": "示例官方公告",
  "original_url": "https://example.com/disclosure",
  "verification_status": "review_required"
}
```

## 3. 系统处理路径

1. 数据源适配器保存标题、日期、来源和原文链接。
2. 事件分类器识别事件类型，并挂载第一个生命周期节点。
3. 后续公告可以继续追加审议、问询、批复、实施或终止节点。
4. 行情与股东背景作为独立上下文展示，不覆盖事件证据。
5. 研究员打开原始公告，记录评级、备注或跟踪决定。
6. 系统导出可追溯的 Markdown / JSON 材料包，供后续研究或 AI 工具使用。

整个流程不会自动下单，也不会生成投资建议或“确定性结论”。
